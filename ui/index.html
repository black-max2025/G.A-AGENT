تحدّث مع الوكيل

كيف يحميك التطبيق

  • الواجهة لا ترسل مسارات للحذف أبداً؛ تُرسل فقط معرّفات نتائج فحص أنتجها التطبيق نفسه.
  • قائمة محمية ثابتة: Windows وProgram Files وProgramData وAppData وجذر القرص والمجلدات الشخصية نفسها.
  • لا يتبع الروابط ولا الـ Junctions، ولا يقرأ ملفات OneDrive غير المحمّلة.
  • الكاش الآمن يُحذف نهائياً (يُعاد تلقائياً)، أما أي شيء آخر فيُنقل إلى سلة المحذوفات ويمكن استرجاعه.
  • الملفات المقفلة أو قيد الاستخدام تُتخطى دون عنف.
  • العقل الذكي محلي بالكامل ولا يرسل بياناتك لأي مكان.

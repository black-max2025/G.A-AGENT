# G.A AGENT

منظّف ويندوز ذكي وآمن (Tauri + Rust) بعقل ذكاء اصطناعي محلي (GGUF عبر llama.cpp).

- **فحص سريع**: مواقع كاش معروفة (متصفحات، Windows، npm/pip، Discord، Telegram، VS Code ...).
- **فحص عميق**: node_modules/target/venv القديمة، مكررات (SHA-256)، ملفات كبيرة قديمة، مثبّتات قديمة.
- **تحليل الفولدرات**: حجم ونوع بيانات كل مجلد وتصنيفه (نظام/شخصي/يُعاد توليده).
- **العقل (AI)**: نموذج GGUF محلي يقترح DELETE/KEEP/ASK مع سبب؛ القرار النهائي لطبقة الأمان.

## الأمان
- الواجهة لا ترسل مسارات للحذف؛ فقط معرّفات نتائج فحص.
- قائمة محمية (Windows, Program Files, ProgramData, AppData, الجذر، المجلدات الشخصية).
- لا يتبع الروابط/Junctions، ويتخطى ملفات OneDrive غير المحمّلة.
- الكاش الآمن يُحذف نهائياً؛ غيره يذهب إلى سلة المحذوفات.

## البناء
GitHub Actions (`.github/workflows/build.yml`) يبني `ga-agent.exe` ومثبّت NSIS على `windows-latest`.
نزّل الملفات من تبويب **Actions → آخر تشغيل → Artifacts**، أو ادفع وسم `v0.1.0` لإنشاء Release.

محلياً: `npm install && npm run tauri -- dev` (يتطلب Rust وWebView2).

## v0.3 — وكيل عام أوفلاين
- **أوفلاين بالكامل**: الوكيل لا يملك أي أداة إنترنت ولا يتصل بأي طرف ثالث، والعقل يعمل على `127.0.0.1` فقط. لا توجد تتبّعات.
- الاتصال الوحيد في التطبيق: تنزيل المحرك (llama.cpp) أو النموذج عندما تضغط زر التجهيز، ومن مواقع محددة فقط (GitHub / Hugging Face). يمكن تجنّبه بالاستيراد اليدوي لملف zip المحرك وملف .gguf.
- **تجهيز تلقائي**: تنزيل النموذج يثبّت المحرك إن كان ناقصاً ثم يشغّل العقل.
- **المجالات**: الملفات والمستندات (ترتيب مجلدات، قراءة docx/xlsx/pptx، بحث داخل الملفات)، البرامج والنظام، الأتمتة (مهام مجدولة، تذكير).
- **مهارات** (وصفات خطوات) وملفات .md خاصة بك في `skills`، **خطة** عمل ظاهرة، **ذاكرة** للتفضيلات (لا تحفظ أسراراً) يمكنك حذفها.
- **روابط محلية مع البرامج**: ملف `.json` داخل `connectors` يصف برنامجاً على جهازك؛ تشغيله يطلب موافقتك دائماً.
- أثر ضغط على الأزرار وحالة انشغال واضحة.

## البريد (Gmail) — اختياري
- بدون ربط حساب يبقى الوكيل أوفلاين. عند الربط: قراءة وبحث في صندوق الوارد فقط، والإرسال لا يتم إلا بعد عرض الرسالة كاملة وموافقتك (مستلم واحد، حد 5 في الساعة، سجل `sent.log`).
- كلمة مرور التطبيق تُحفظ في Windows Credential Manager ولا يراها النموذج. الاتصال فقط بـ imap.gmail.com وsmtp.gmail.com.
- نص الرسائل الواردة يُعامل كبيانات غير موثوقة (حماية من حقن الأوامر).

## v0.4 — هوية جديدة، 5 لغات، أداء للأجهزة المتواضعة

- **اللغات:** العربية، English، Bahasa Indonesia، Français، Italiano (من القائمة أسفل الشريط الجانبي). الوكيل يرد بلغة الواجهة.
- **الأداء (Core i5-2400 / 8 جيجا):** المحرك يعمل على نافذة عشوائية محلية بمفتاح سري، حدّ معالج صارم عبر Windows Job Object (افتراضي 60%)، أولوية منخفضة، خيطان فقط، وتفريغ من الذاكرة عند الخمول. كل ذلك من «الإعدادات».
- **طرق جديدة لتوفير المساحة:** (1) الخزنة: تقطيع المجلدات القديمة إلى أجزاء ثابتة، ضغط zstd، تخزين مرة واحدة للأجزاء المتطابقة، تحقق قبل الحذف، واسترجاع بفحص البصمة. (2) دمج الملفات المتطابقة بروابط صلبة داخل القرص نفسه مع تراجع كامل.
- **جدولة حقيقية:** مهام في Windows Task Scheduler تعمل والتطبيق مغلق وتلحق إن كان الجهاز مطفأً، مع إحساس بالوقت (الساعة والتاريخ والعدّ التنازلي).
- **الإنترنت الآمن:** بحث ويب عبر HTTPS فقط وعناوين عامة فقط، لا تُرسل فيه بياناتك، وحد 30 بحثاً/ساعة، ونص الويب يُعامل كمعلومة لا كأوامر.
- **الرسائل:** Gmail (قراءة، وإرسال بموافقتك) وتيليجرام (بوت خاص + اقتران بكود، رسائل الغرباء إلى «الوارد» دون رد تلقائي) وواتساب (تجهيز الرد وفتح واتساب والنص جاهز، وأنت تضغط إرسال).
- **حدود صادقة:** لا يوجد وسيلة آمنة للرد التلقائي على واتساب الشخصي؛ بوت تيليجرام لا يستقبل إلا ممن كلّمه؛ محادثة تيليجرام عن بُعد للقراءة فقط.
